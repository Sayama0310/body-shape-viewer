体形モデル（Anny / MakeHuman）に含まれる、集団ごとの平均的な体格の傾向です。統計的な傾向のモデルで、個人の特徴や出自を表すものではありません。標準はこれらを等分に混ぜたものです。

肌の色

服は体形に合わせて変形します（試作）。

入力した値に体形を近づけます（空欄はモデルの値のまま）。胸囲はバストトップ、アンダーバストはその下の最も細いところ、ウエストは胴の最も細いところ、ヒップはお尻の最も太いところ、二の腕は肩と肘の中ほど、太もも・ふくらはぎは最も太いところ、足首は最も細いところの周囲です。左右がある部位は左右同じ値として扱います。

使い方

  • 身長・体重はスライダーか数値で入力します。性別で体形の傾向が変わります。
  • 下のパネルを引き出し、「周囲長（任意）」を開いて胸囲・ウエスト・ヒップ・二の腕・太ももなどを入れると、体形がその値に近づきます。空欄ならモデルの値を表示します。年齢と筋肉量（自動または手動）でも体形が変わります。
  • 3D表示は1本指で回転、2本指でピンチすると拡大・縮小します。右上のボタンで正面・横・後ろに切り替えられます。
  • モデルで表せない組み合わせのときは、近い体形を表示して画面下に注記を出します。

データの扱い

入力した値はこの端末の中だけで計算・保存し、外部には送信しません。ホーム画面に追加するとオフラインでも使えます。
