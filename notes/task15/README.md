# タスク15: 年齢を変えても体形がほとんど変わらない — 調査結果

比較画像: [`age-20-50-80.png`](age-20-50-80.png)（男性 170cm / 65kg・女性 158cm / 52kg、20・50・80歳、正面と横）

## 切り分け

| 原因の候補 | 結果 | 根拠 |
|---|---|---|
| (a) データ・合成の誤り | 該当しない | 書き出し時の検証で、補間結果と Anny 本体の出力の差は最大 8.6mm（20〜80歳のランダムな8体形） |
| (b) `fit` による打ち消し | 小さい（女性で2割程度） | 下表の「fit あり / なし」 |
| (c) Anny の較正上もともと差が小さい | 主因 | 20〜80歳は "young"→"old" のうち 32〜67% にしか当たらない |

20歳→80歳の頂点の移動量（体格の傾向は標準）:

| | fit なし（Anny のパラメータ固定） | fit あり（身長・体重を合わせる） | 参考: "young"→"old" 全体 |
|---|---|---|---|
| 男性 | 平均 14.8mm / 最大 27mm | 平均 14.6mm / 最大 32mm | 平均 42mm / 最大 80mm |
| 女性 | 平均 6.2mm / 最大 14mm | 平均 4.7mm / 最大 15mm | 平均 23mm / 最大 38mm |

fit なしでの計測値の変化（男性, Anny の height 0.3・weight 0.5）: 身長 168.8→167.7cm、体重 62.7→61.9kg、ウエスト 81.2→83.4cm、ヒップ 95.2→96.3cm。
`fit` は身長と体重を入力値に戻す（Anny が加齢で身長を約1cm縮め体重を少し減らすぶんを打ち消す）が、ウエストが太くなるなど形の変化は残っている。

Anny の年齢の対応（`shape_calibration` の `morphological_age_mapping`）は 18歳 = 0.77、64歳 = 0.83、110歳 = 1.0 で、
18〜64歳の46年がわずか 0.06 に詰め込まれている。そのため Anny に忠実なままだと、20〜80歳での見た目の差は小さい。

## 選択肢（要相談）

1. **このまま（Anny に忠実）**: 差が小さいことを画面の説明に書く
2. **年齢の効きを強める係数を入れる**: 例えば 20〜80歳を "young"〜"old" の 0〜1 全体に割り当てる（差は約3倍、80歳が Anny の110歳相当の体形になる）
3. **Anny の年齢の対応を独自の表に置き換える**: 例えば 25歳 = "young"（MakeHuman の元の定義）、90歳 = "old" とし、間を線形にする（2 より穏やか）
4. **`fit` で身長を合わせない選択肢を足す**: 加齢による身長の縮みも見せたい場合（身長の入力の意味が変わるので UI の工夫が要る）

いずれも Anny の較正から外れるので、選ぶ場合は説明（ヘルプ）にもその旨を書く。
顔の加齢には Anny の局所調整 `head-age-incr` も使える（今は使っていない）。
